# proyecto-de-software-teoria-act1

Prompt usado para ambas ias:

Generá un sitio web estático (sin scripts) para reseñar juegos de mesa de una ludoteca. Requisitos:

Los juegos se dividen en tres categorías: estrategia, cartas y familiares.

Debe haber una barra de navegación con enlaces a: información de contacto (un formulario simple), información de quién mantiene el sitio, y catálogo de juegos distribuido en las tres categorías.

Al elegir una categoría, se deben mostrar las reseñas de los juegos correspondientes en la zona central de la página, de forma estática.

Cada juego debe mostrar su portada y un enlace al reglamento.

Incluí al menos 2 juegos por categoría.

Las portadas van en un directorio "imagenes" (formato .png) y los manuales descargables en un directorio "reglamentos" (formato .pdf). Ejemplo: imagenes/truco.png, reglamentos/truco.pdf.

El sitio debe ser responsivo.

Solo se debe usar HTML y CSS. 

Todas las reglas de estilo deben ir en un archivo separado llamado estilosIA.css.

El estilo sera minimalista y los colores principales seran rojo y marron.

Entregá la estructura completa de archivos y el código de cada uno.
