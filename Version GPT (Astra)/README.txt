PROYECTO LUDOTECA

Sitio web estático creado únicamente con HTML y CSS.

Abrir index.html en un navegador para comenzar.

Estructura:
- HTML: páginas del sitio
- estilosIA.css: todos los estilos
- imagenes/: portadas PNG de ejemplo
- reglamentos/: PDFs de ejemplo

Las imágenes y reglamentos incluidos son archivos de ejemplo para que el sitio funcione sin enlaces rotos. Pueden reemplazarse conservando los mismos nombres.
